Cómo instalarla

  1. Toca Descargar para Android. Si el navegador avisa que el archivo puede ser dañino, elige Descargar de todas formas.
  2. Abre el archivo descargado desde las notificaciones o desde la carpeta Descargas.
  3. Android te pedirá permiso para instalar apps de esta fuente. Actívalo y vuelve atrás.
  4. Toca Instalar. Listo: busca el ícono de QuizClip.

Android muestra estos avisos con cualquier app que no viene de Google Play. Para actualizar, descarga la nueva versión desde esta página e instálala encima: no pierdes tus proyectos.

¿El botón Exportar no funciona? Actualiza Android System WebView y Chrome desde Google Play y vuelve a intentarlo.
